# PIA01 -- Mi primer repositorio en GitHub

Este repositorio forma parte de la actividad PIA01 y recoge una primera
toma de contacto con GitHub, el lenguaje de marcado Markdown y la
programación con Python.

## Objetivos de la actividad

-   Crear una cuenta personal en GitHub.
-   Crear un repositorio para guardar los archivos de la actividad.
-   Utilizar Markdown para documentar el trabajo mediante un archivo
    `README.md`.
-   Crear un programa sencillo en Python que muestre el mensaje «Hola
    Mundo».

## Contenido del repositorio

  Archivo           Descripción
  ----------------- ----------------------------------------------
  `README.md`       Documentación y explicación de la actividad.
  `hola_mundo.py`   Primer programa realizado en Python.

## Ejecución del programa

Para ejecutar el programa, es necesario tener Python instalado. Desde
una terminal, situándose en la carpeta del repositorio, se puede
ejecutar:

``` bash
python hola_mundo.py
```

El resultado esperado es:

``` text
Hola Mundo
```

## Aprendizaje

Con esta práctica se da el primer paso en el uso de GitHub como
herramienta para almacenar y organizar proyectos, y se aprende a
documentar archivos con Markdown y a ejecutar un programa básico en
Python.
